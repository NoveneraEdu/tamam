# تمام

تنظيم تاسكات الشغل والدراسة والمدفوعات. تكتب أو تسجّل فويس نوت بالعامية، والـ AI يحوّلها لتاسكات بمجالها ونوعها وميعادها ومبلغها.

- الواجهة: ملف `index.html` واحد (PWA تتنزل على الموبايل)، منشور على GitHub Pages.
- البيانات: Supabase (نفس مشروع سهم `daftar-elshoraka`)، جدول `tm_items` محمي بـ RLS لإيميل صاحب الحساب بس.
- الـ AI: دالة `supabase/functions/tamam-ai` بتكلم OpenRouter. المفتاح متخزن في الجدول الخاص `integration_keys` (id = `openrouter`) ومبيوصلش للمتصفح، وبيتحط من شاشة الإعدادات في التطبيق.
- الفويس بيتسجل في المتصفح ويتحول WAV 16kHz ويتبعت للموديل (افتراضياً `google/gemini-3.6-flash`) اللي بيسمعه ويطلّع المهام.
